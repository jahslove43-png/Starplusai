Features

Everything needed to run a focused review workflow.

StarPlusAI keeps customer records, review requests, incoming reviews and approved social proof connected.

Customer management

Add and manage customer names, email addresses and optional phone numbers.

Review requests

Create unique review requests with a secure public token and 30-day expiration.

Email invitations

Send review invitations through the configured Supabase Edge Function and Resend integration.

Moderation

Reviews enter a pending state and can be approved, rejected or returned to pending.

Public widget

Display approved reviews through a public feed that calculates its summary across the full approved dataset.

Authentication

Supabase Auth supports signup, login, email verification and password recovery. Google OAuth is available when configured.
