FAQ

Answers about the current StarPlusAI product.

How long is the trial?

The current trial period is 3 days. The end time is stored in the database rather than being controlled only by browser JavaScript.

Do you charge my card during the trial?

No paid checkout is active in the current product, so the trial buttons do not charge an account.

Can a review request be used twice?

No. Once a request is completed, the public review function rejects another submission.

How long are review links valid?

The current review-request workflow uses a 30-day expiration period.

Which reviews appear in the public widget?

Only approved reviews are exposed. Pending and rejected reviews are not part of the public feed.

Is Google login available?

Google OAuth is supported when the provider is configured in Supabase. It is not claimed as active unless that configuration has been verified.

How are emails sent?

Authentication emails use the configured Supabase email hook, while review-request and lifecycle emails use server-side Edge Functions with Resend.
